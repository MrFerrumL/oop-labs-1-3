## Контрольные вопросы

### 1. Что такое наследование и какое отношение оно моделирует

Наследование создаёт специализацию существующего класса и выражает отношение «является»: Manager является Employee. Общие свойства задаются в Employee, специальные — в Manager и Developer.

### 2. Что такое переопределение и чем оно отличается от перегрузки

Переопределение задаёт в подклассе новую реализацию унаследованного экземплярного метода с совместимой сигнатурой. Перегрузка добавляет методы с другим списком параметров. Один только другой возвращаемый тип не создаёт перегрузку.

### 3. Что такое полиморфизм и где он используется в работе

Переменная Employee может ссылаться на Manager или Developer. В цикле по Employee[] вызов calculateBonus() выбирает реализацию фактического объекта. Для 150000 у Manager получается 22500, для 120000 и доплаты 3000 у Developer — 15000.

### 4. Что такое абстрактный класс и можно ли создать его объект

Класс с abstract нельзя создать напрямую через new. Он может иметь поля, конструктор, реализованные и абстрактные методы. Конкретный подкласс реализует оставшиеся абстрактные методы. В основной программе Employee конкретный, как требует раздел с заданием.

### 5. Что такое интерфейс и чем он отличается от абстрактного класса

Интерфейс задаёт контракт поведения, например Reportable. У него нет состояния отдельного экземпляра и конструкторов. Абстрактный класс может хранить состояние и инициализировать его. В Java 17 интерфейсы также поддерживают default, static и private методы.

### 6. Можно ли наследовать несколько классов и реализовывать несколько интерфейсов

Класс Java имеет один непосредственный суперкласс, но может реализовать несколько интерфейсов. Сам интерфейс может расширять несколько интерфейсов.

### 7. Для чего нужна аннотация Override

Она поручает компилятору проверить, что метод действительно переопределяет унаследованный метод либо реализует метод интерфейса. Опечатка в имени или параметрах будет обнаружена при компиляции.

### 8. Что означает super

super(...) вызывает конструктор непосредственного суперкласса. super.toString() вызывает реализацию метода суперкласса. В Java 17 явный вызов конструктора должен стоять первой инструкцией конструктора.

### 9. Когда выбирать абстрактный класс и когда интерфейс

Абстрактный класс подходит родственным объектам с общим состоянием и общей реализацией. Интерфейс подходит для общей способности разных типов, например формирования отчёта. Оба механизма можно использовать совместно.

### 10. Какие ограничения накладывает final

final-класс нельзя наследовать; final-метод нельзя переопределять; final-переменной можно присвоить значение только один раз. final-ссылка не делает сам объект неизменяемым. Константой времени компиляции является лишь определённая категория final-переменных.

### Developer.java

```java
package com.university.lab03;

/** Разработчик с дополнительной технической премией. */
public class Developer extends Employee implements Reportable {
    private static final double BONUS_RATE = 0.10;
    private final String programmingLanguage;
    private final double techBonus;

    /** Инициализирует сотрудника, язык и техническую премию. */
    public Developer(String name, String department, double salary,
                     String programmingLanguage, double techBonus) {
        super(name, department, salary);
        this.programmingLanguage = requireText(programmingLanguage, "Язык");
        if (!Double.isFinite(techBonus) || techBonus < 0) {
            throw new IllegalArgumentException("Техническая премия должна быть конечной и >= 0");
        }
        this.techBonus = techBonus;
    }

    /** Возвращает язык программирования. */
    public String getProgrammingLanguage() { return programmingLanguage; }

    /** Возвращает техническую премию. */
    public double getTechBonus() { return techBonus; }

    /** Вычисляет десять процентов оклада плюс техническую премию. */
    @Override
    public double calculateBonus() { return getSalary() * BONUS_RATE + techBonus; }

    /** Расширяет базовое описание. */
    @Override
    public String toString() {
        return super.toString() + " — разработчик " + programmingLanguage;
    }

    /** Возвращает заглушку отчёта без вымышленных выполненных задач. */
    @Override
    public String generateReport() {
        return "Отчёт разработчика " + getName()
                + ": список завершённых задач — заглушка";
    }
}
```

### Employee.java

```java
package com.university.lab03;

/** Базовый сотрудник; также используется как тип массива. */
public class Employee {
    private static final double BASE_BONUS_RATE = 0.05;
    private final String name;
    private final String department;
    private final double salary;

    /** Проверяет и инициализирует общую часть сотрудника. */
    public Employee(String name, String department, double salary) {
        this.name = requireText(name, "Имя");
        this.department = requireText(department, "Отдел");
        if (!Double.isFinite(salary) || salary <= 0) {
            throw new IllegalArgumentException("Оклад должен быть положительным и конечным");
        }
        this.salary = salary;
    }

    /** Возвращает имя сотрудника. */
    public String getName() { return name; }

    /** Возвращает отдел сотрудника. */
    public String getDepartment() { return department; }

    /** Возвращает оклад сотрудника. */
    public double getSalary() { return salary; }

    /** Вычисляет базовую премию в размере пяти процентов. */
    public double calculateBonus() { return salary * BASE_BONUS_RATE; }

    /** Возвращает общую часть описания сотрудника. */
    @Override
    public String toString() { return name + " (" + department + ")"; }

    /** Проверяет обязательную строку для этого класса и подклассов. */
    protected static String requireText(String value, String field) {
        if (value == null || value.isBlank()) {
            throw new IllegalArgumentException(field + " не может быть пустым");
        }
        return value.strip();
    }
}
```

```java
import java.util.List;
import java.util.Locale;

/** Демонстрирует полиморфизм базового и интерфейсного типов. */
public class Main {
    /** Выводит премии пяти сотрудников и отчёты четырёх из них. */

        Manager manager1 = new Manager("Иванов", "IT", 150000, 5);
        Developer developer1 = new Developer("Петров", "IT", 120000, "Java", 3000);
        Manager manager2 = new Manager("Сидорова", "Продажи", 100000, 3);

        Employee employee = new Employee("Кузнецов", "Поддержка", 80000);
        Employee[] employees = {manager1, developer1, manager2, developer2, employee};
        System.out.println("=== Полиморфизм ===");
        for (Employee item : employees) {
            System.out.printf(Locale.ROOT, "%s — бонус: %.2f руб.%n",
                    item, item.calculateBonus());
        }
        List<Reportable> reporters = List.of(manager1, developer1, manager2, developer2);
        System.out.println("\n=== Интерфейс Reportable ===");
        for (Reportable reporter : reporters) {
            System.out.println(reporter.generateReport());
        }
    }
}
```

### Manager.java

```java
package com.university.lab03;

/** Менеджер является сотрудником и умеет формировать отчёт. */
public class Manager extends Employee implements Reportable {
    private static final double BONUS_RATE = 0.15;
    private final int subordinatesCount;

    /** Инициализирует базовую часть и число подчинённых. */
    public Manager(String name, String department, double salary,
                   int subordinatesCount) {
        super(name, department, salary);
        if (subordinatesCount < 0) {
            throw new IllegalArgumentException("Число подчинённых не может быть отрицательным");
        }
        this.subordinatesCount = subordinatesCount;
    }

    /** Возвращает количество подчинённых. */
    public int getSubordinatesCount() { return subordinatesCount; }

    /** Вычисляет премию менеджера в размере пятнадцати процентов. */
    @Override
    public double calculateBonus() { return getSalary() * BONUS_RATE; }

    /** Расширяет базовое описание. */
    @Override
    public String toString() {
        return super.toString() + " — менеджер, подчинённых: " + subordinatesCount;
    }

    /** Возвращает заглушку отчёта согласно условию работы. */
    @Override
    public String generateReport() {
        return "Отчёт менеджера " + getName() + ": " + subordinatesCount
                + " подчинённых (список — заглушка)";
    }
}
```
