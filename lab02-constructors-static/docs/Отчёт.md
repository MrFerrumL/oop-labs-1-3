## Результат

Класс Book дополнен четырьмя конструкторами, общим счётчиком, статической фабрикой и двумя форматами описания. Все пути инициализации проходят через основной конструктор. Счётчик увеличивается только после успешной проверки данных.

## Четыре конструктора

Book() задаёт id=0, название «Без названия», автора «Неизвестен» и year=0. Полный конструктор принимает четыре поля. Конструктор без id передаёт ноль вместо id; конструктор из двух строк дополнительно задаёт year=0. Сокращённые варианты делегируют работу через this(...).

## Общий счётчик и выдача id

counter учитывает успешно созданные объекты в текущем процессе JVM. Увеличение стоит в конце основного конструктора, поэтому делегирование не даёт двойного подсчёта, а ошибка в данных не увеличивает counter. lastAssignedId отслеживает наибольший назначенный положительный id; фабрика выдаёт следующий.

## Почему счётчик отделён от id

В разделе задания конструкторы без id обязаны сохранять ноль. Поэтому количество книг и идентификатор — разные величины. Явный id=10 приводит к следующему фабричному id=11, хотя объектов к этому моменту только пять. Повторные явно заданные id не запрещаются: глобальный реестр уникальности в этой работе не реализуется.

## Перегрузка и ограничения

getDescription() формирует полное описание, getDescription(true) — краткое, getDescription(false) делегирует полному методу. Фабрика рассчитана на однопоточный учебный пример. При перезапуске JVM статические значения сбрасываются.

## Контрольные вопросы

### 1. Что такое перегрузка конструкторов

Это несколько конструкторов одного класса с различными списками параметров. В Book используются варианты без параметров, со всеми полями, без id и только с названием и автором.

### 2. Как вызвать один конструктор из другого

В Java 17 вызов this(...) записывается первой инструкцией конструктора. Например, Book(String title, String author) передаёт параметры основному конструктору с id = 0 и year = 0.

### 3. Чем статическое поле отличается от нестатического

Статическое поле принадлежит классу и общее для его экземпляров в рамках одного загрузчика классов. Нестатическое поле принадлежит конкретному объекту. counter общий, а title у каждой книги свой.

### 4. Может ли статический метод обращаться к нестатическим полям

Не напрямую: у static-метода нет текущего this. Обратиться можно через явную ссылку на объект, например book.getTitle(). К статическому counter метод getCounter() обращается непосредственно.

### 5. Что такое фабричный метод и каковы его преимущества

В этой работе статическая фабрика createBook создаёт и возвращает книгу. Она имеет понятное имя и скрывает выдачу id. В общем случае фабрика может возвращать подкласс или ранее созданный объект. Это не обязательно паттерн GoF Factory Method.

### 6. Чем перегрузка отличается от переопределения

При перегрузке имя одинаково, а параметры различаются; выбор сигнатуры происходит при компиляции. При переопределении подкласс меняет реализацию унаследованного экземплярного метода; реализация выбирается по фактическому объекту при выполнении.

### 7. Как обратиться к статическому методу

Через имя класса: Book.getCounter() или Book.createBook(...). Вызывать через переменную объекта технически возможно, но это скрывает принадлежность метода классу.

### 8. Для чего применяется this

Для ссылки на текущий объект, разрешения совпадения имён поля и параметра, передачи текущего объекта и вызова другого конструктора через this(...). В static-контексте this недоступен.

## Полный листинг программы

### Book.java

```java
package com.university.lab02;

import java.time.Year;

/** Книга с закрытыми полями и проверкой входных данных. */
public final class Book {

    private long id;
    private String title = "Без названия";
    private String author = "Неизвестен";
    private int year;
    private static int counter;
    private static long lastAssignedId;

    /** Создаёт книгу с безопасными значениями по умолчанию. */
    public Book() { this(0, "Без названия", "Неизвестен", 0); }

    /** Основной конструктор; учитывает только успешно созданные книги. */
    public Book(long id, String title, String author, int year) {
        setTitle(title);
        setAuthor(author);
        setYear(year);
        setId(id);
        counter++;
    }

    /** Создаёт книгу с незаданным идентификатором. */
    public Book(String title, String author, int year) {
        this(0, title, author, year);
    }

    /** Создаёт книгу с незаданными идентификатором и годом. */
    public Book(String title, String author) {
        this(0, title, author, 0);
    }

    /** Возвращает число успешно созданных объектов в текущем запуске. */
    public static int getCounter() { return counter; }

    /** Выдаёт следующий id выше всех ранее назначенных положительных id. */
    public static Book createBook(String title, String author, int year) {
        long nextId = Math.incrementExact(lastAssignedId);
        return new Book(nextId, title, author, year);
    }

    /** Выбирает краткий или полный формат описания. */
    public String getDescription(boolean shortFormat) {
        return shortFormat ? title + " (" + year + ")" : getDescription();
    }

    /** Принимает неотрицательный id; ноль означает, что id не задан. */
    public void setId(long id) {
        if (id < 0) {
            throw new IllegalArgumentException("Id не может быть отрицательным");
        }
        this.id = id;
        lastAssignedId = Math.max(lastAssignedId, id);
    }

    /** Возвращает идентификатор книги. */
    public long getId() { return id; }

    /** Возвращает название книги. */
    public String getTitle() { return title; }

    /** Проверяет и сохраняет непустое название. */
    public void setTitle(String title) {
        this.title = requireText(title, "Название");
    }

    /** Возвращает автора книги. */
    public String getAuthor() { return author; }

    /** Проверяет и сохраняет непустое имя автора. */
    public void setAuthor(String author) {
        this.author = requireText(author, "Автор");
    }

    /** Возвращает год издания. */
    public int getYear() { return year; }

    /** Принимает год от нуля до текущего включительно. */
    public void setYear(int year) {
        int currentYear = Year.now().getValue();
        if (year < 0 || year > currentYear) {
            throw new IllegalArgumentException("Год: от 0 до " + currentYear);
        }
        this.year = year;
    }

    /** Возвращает полное описание книги. */
    public String getDescription() {
        return "\"" + title + "\" — " + author + " (" + year + ")";
    }

    /** Позволяет печатать книгу через println. */
    @Override
    public String toString() { return getDescription(); }

    private static String requireText(String value, String field) {
        if (value == null || value.isBlank()) {
            throw new IllegalArgumentException(field + " не может быть пустым");
        }
        return value.strip();
    }
}
```

```java
package com.university.lab02;

/** Демонстрация лабораторной работы 2. */
public class Main {

    /** Показывает четыре конструктора, фабрику и перегрузку методов. */
    public static void main(String[] args) {
        Book empty = new Book();
        Book full = new Book(10, "Война и мир", "Толстой Л.Н.", 1869);
        Book withoutId = new Book("Преступление и наказание", "Достоевский Ф.М.", 1866);
        Book titleAuthor = new Book("Рассказы", "Чехов А.П.");
        Book factory = Book.createBook("Мастер и Маргарита", "Булгаков М.А.", 1967);
        System.out.println("=== Четыре конструктора и фабрика ===");
        Book[] books = {empty, full, withoutId, titleAuthor, factory};
        for (Book book : books) {
            System.out.println("id=" + book.getId() + ": " + book);
        }
        System.out.println("Краткое описание: " + withoutId.getDescription(true));
        System.out.println("Полное описание: " + withoutId.getDescription(false));
        int before = Book.getCounter();
        try {
            new Book(" ", "Автор", 2020);
        } catch (IllegalArgumentException exception) {
            System.out.println("Ожидаемая ошибка: " + exception.getMessage());
        }
        System.out.println("Всего создано книг: " + Book.getCounter());
        System.out.println("Счётчик после ошибки не изменился: "
                + (before == Book.getCounter()));
    }
}
```
