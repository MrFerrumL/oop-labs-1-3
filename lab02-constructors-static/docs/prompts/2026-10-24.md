## Полученный результат

Класс Book дополнен четырьмя конструкторами, общим счётчиком, статической фабрикой и двумя форматами описания. Все пути инициализации проходят через основной конструктор. Счётчик увеличивается только после успешной проверки данных.

Полный результат находится в src/main/java, src/test/java и docs/Отчёт.md.

## Анализ и изменения

Код сопоставлен с общим заданием из методички; произвольный индивидуальный вариант не выбирался.
getDescription() формирует полное описание, getDescription(true) — краткое, getDescription(false) делегирует полному методу. Фабрика рассчитана на однопоточный учебный пример. При перезапуске JVM статические значения сбрасываются.
Настроена кодировка UTF-8 для Windows PowerShell и Java. Для обнаружения javac используется разбор версии и допускается JDK 17+.
В Book из второй работы класс объявлен final, чтобы конструктор не вызывал переопределяемые методы ещё не инициализированного подкласса.
