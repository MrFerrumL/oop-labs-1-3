## Запуск на Windows

1. Скачайте или клонируйте репозиторий.
2. Откройте `RUN_ALL.cmd` для запуска трёх демонстраций либо `run.cmd` нужной работы.
3. Откройте `TEST_ALL.cmd` для выполнения 87 автономных проверок.

Также можно запустить из PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./run.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./run.ps1 -Test
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./run.ps1 -Lab 2
```

Требуется JDK 17 или выше. Скрипт ищет `javac` через `JAVA_HOME`, `PATH` и стандартные папки установки, включая JBR JetBrains на исходном ПК. Системные настройки не изменяются.

## Открытие в Java IDE

Откройте корневую папку или корневой `pom.xml` в IntelliJ IDEA: все три работы откроются в одном проекте. Выберите JDK 17+. В верхнем списке конфигураций доступны `Лаба 1`, `Лаба 2`, `Лаба 3` и три конфигурации `Тесты лабы`. Выберите нужную работу и нажмите зелёный треугольник Run. Также каждую работу можно открыть отдельно через её `pom.xml`.
Автономные тесты запускаются через `TEST_ALL.cmd`; они не зависят от JUnit и не привязаны к `mvn test`.
