## Контрольные вопросы

### 1. Что такое класс и объект и в чём их различие

Класс задаёт поля и методы. Объект — конкретный экземпляр класса со своим состоянием. Book — класс; first и second в Main ссылаются на разные объекты Book.

### 2. Какие модификаторы доступа существуют в Java

public — доступ из любого кода, которому доступен сам тип; protected — из своего пакета и из подклассов с дополнительными ограничениями вне пакета; доступ без модификатора — внутри пакета; private — внутри объявляющего класса и его вложенного контекста.

### 3. Что такое инкапсуляция и зачем она нужна

Инкапсуляция объединяет состояние и поведение и задаёт правила доступа к данным. Закрытое поле year изменяется через setYear, поэтому неправильный год нельзя записать обычным внешним обращением.

### 4. Чем конструктор отличается от обычного метода

Конструктор инициализирует новый объект, имеет имя класса и не имеет возвращаемого типа. Обычный метод описывает действие, имеет возвращаемый тип либо void и вызывается отдельно. Конструкторы не наследуются.

### 5. Для чего используется this

this обозначает текущий объект: this.year — его поле. В конструкторе запись this(...) вызывает другой конструктор того же класса.

### 6. Что такое классы обёртки и автоупаковка

Integer, Long, Double и Boolean — объектные представления примитивов int, long, double и boolean. Integer n = 42 выполняет автоупаковку; int x = n — распаковку. Распаковка null вызывает NullPointerException.

### 7. Почему прямой доступ к полям считается плохой практикой

Внешний код мог бы присвоить year = -1 и обойти проверку. Закрытое поле и проверяющий метод сохраняют ограничения и позволяют менять внутреннее устройство класса без изменения внешнего интерфейса.

### 8. Какие преимущества даёт ООП

Классы позволяют описывать сущности предметной области, инкапсуляция локализует ограничения, композиция и наследование помогают повторно использовать код, а полиморфизм позволяет работать с разными реализациями через общий тип.

## Полный листинг программы

### Book.java

```java
package com.university.lab01;

import java.time.Year;

/** Книга с закрытыми полями и проверкой входных данных. */
public final class Book {

    private long id;
    private String title = "Без названия";
    private String author = "Неизвестен";
    private int year;

    /** Принимает неотрицательный id; ноль означает, что id не задан. */
    public void setId(long id) {
        if (id < 0) {
            throw new IllegalArgumentException("Id не может быть отрицательным");
        }
        this.id = id;
    }

    /** Возвращает идентификатор книги. */
    public long getId() { return id; }

    /** Возвращает название книги. */
    public String getTitle() { return title; }

    /** Проверяет и сохраняет непустое название. */
    public void setTitle(String title) {
        this.title = requireText(title, "Название");
    }

    /** Возвращает автора книги. */
    public String getAuthor() { return author; }

    /** Проверяет и сохраняет непустое имя автора. */
    public void setAuthor(String author) {
        this.author = requireText(author, "Автор");
    }

    /** Возвращает год издания. */
    public int getYear() { return year; }

    /** Принимает год от нуля до текущего включительно. */
    public void setYear(int year) {
        int currentYear = Year.now().getValue();
        if (year < 0 || year > currentYear) {
            throw new IllegalArgumentException("Год: от 0 до " + currentYear);
        }
        this.year = year;
    }

    /** Возвращает полное описание книги. */
    public String getDescription() {
        return "\"" + title + "\" — " + author + " (" + year + ")";
    }

    /** Позволяет печатать книгу через println. */
    @Override
    public String toString() { return getDescription(); }

    private static String requireText(String value, String field) {
        if (value == null || value.isBlank()) {
            throw new IllegalArgumentException(field + " не может быть пустым");
        }
        return value.strip();
    }
}
```

### Main.java

```java
package com.university.lab01;

/** Демонстрация лабораторной работы 1. */
public class Main {

    /** Создаёт и выводит три независимых объекта. */
    public static void main(String[] args) {
        Book first = makeBook(1, "Война и мир", "Толстой Л.Н.", 1869);
        Book second = makeBook(2, "Мастер и Маргарита", "Булгаков М.А.", 1967);
        Book third = makeBook(3, "Преступление и наказание", "Достоевский Ф.М.", 1866);
        Book[] books = {first, second, third};
        System.out.println("=== Список книг ===");
        for (int i = 0; i < books.length; i++) {
            System.out.println((i + 1) + ". " + books[i].getDescription());
        }
        try {
            first.setYear(-1);
        } catch (IllegalArgumentException exception) {
            System.out.println("Ожидаемая ошибка: " + exception.getMessage());
        }
        System.out.println("Год после ошибки: " + first.getYear());
    }

    private static Book makeBook(long id, String title, String author, int year) {
        Book book = new Book();
        book.setId(id);
        book.setTitle(title);
        book.setAuthor(author);
        book.setYear(year);
        return book;
    }
}
```
