# Лабораторная работа 1

Первый класс и инкапсуляция. Общее задание без индивидуального варианта.

Создан класс Book с приватными полями id, title, author и year. Доступ к состоянию осуществляется через getter и setter. В Main созданы три независимых объекта, выведены их описания и показан отказ при попытке записать отрицательный год.

## Запуск

На этом ПК дважды нажмите run.cmd. Скрипт найдёт JDK 17+.
Проверка: в родительской папке откройте TEST_ALL.cmd.
Открытие в среде разработки: откройте pom.xml как Maven-проект, выберите JDK 17+ и запустите com.university.lab03.Main.
Maven является описанием проекта для IDE; для запуска через cmd скачивание Maven не требуется.
Автономные проверки LabTest запускаются скриптом TEST_ALL.cmd, а не командой mvn test.

## Файлы

- src/main/java — все исходники с комментариями.
- src/test/java — автономные проверки, ошибки приводят к ненулевому коду завершения.
- docs/Отчёт.md — отчёт с полным листингом программы.
- docs/console-output.txt — фактический вывод Main.
- docs/test-results.txt — результат проверок.
- docs/prompts — журнал ИИ.
