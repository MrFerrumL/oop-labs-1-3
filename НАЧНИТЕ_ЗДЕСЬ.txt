ПЕРВЫЕ ТРИ ЛАБОРАТОРНЫЕ ПО ООП НА JAVA

Выполнены общие задания без индивидуальных вариантов.

1. Документы/Теория_ООП_лабы_1–3.docx — отдельный конспект теории.
2. Документы/Лабораторная_1_отчёт.docx — пояснения и ответы к первой работе.
3. Документы/Лабораторная_2_отчёт.docx — пояснения и ответы ко второй работе.
4. Документы/Лабораторная_3_отчёт.docx — пояснения и ответы к третьей работе.

ЗАПУСК

Дважды нажмите RUN_ALL.cmd: последовательно запустятся все три программы.
Для отдельной работы используйте run.cmd в папке lab01, lab02 или lab03.
TEST_ALL.cmd запускает 87 автоматических проверок.
Проверьте, что открываете именно файл с расширением .cmd.

СТРУКТУРА

Каждая папка lab — самостоятельный Maven-проект с pom.xml.
src/main/java — исходники; src/test/java — проверки.
docs/Отчёт.md — полный отчёт в Markdown со всеми листингами.
docs/console-output.txt — реальный вывод программы.
docs/test-results.txt — результаты проверки.
docs/prompts/2026-10-24.md — журнал использования ИИ.
Источники — сохранённые исходные задания и общая методичка.

Java 17+. На этом ПК скрипты используют JDK 21.0.8 из JetBrains CLion.
JAVA_HOME и системный PATH не изменяются. Java 8 для этих программ недостаточно.
При переносе на другой ПК нужен JDK 17+ в JAVA_HOME, PATH или стандартной папке установки.
Для открытия в Java IDE выберите pom.xml и JDK 17+; затем запустите Main нужного проекта.

Перед сдачей заполните ФИО, группу, учебное заведение и преподавателя на титульных листах.
Имена и реквизиты не выдумывались. Отчёты содержат текстовый протокол выполнения.
Образец титульного листа учреждения в источнике не приложен; использован нейтральный макет.
Использование Codex отражено в журнале ИИ; ответы на вопросы позволяют подготовиться к защите.
